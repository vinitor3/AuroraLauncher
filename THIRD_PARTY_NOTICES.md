# Avisos de terceiros

## Bibliotecas do Aurora Core

O Core inclui bibliotecas de terceiros em alguns de seus JARs. A pasta de licenças contém os avisos dos autores e os termos de redistribuição.

| Biblioteca | Uso no Core | Termos e origem |
| --- | --- | --- |
| Gson | Leitura e escrita de JSON | [Apache 2.0](apps/aurora-core/licenses/Gson-LICENSE.txt) · [Google Gson](https://github.com/google/gson) |
| Java-WebSocket | Canal local entre o jogo e o launcher | [MIT](apps/aurora-core/licenses/Java-WebSocket-LICENSE.txt) · [Java-WebSocket](https://github.com/TooTallNate/Java-WebSocket) |
| SLF4J | API de registro usada pelo transporte | [MIT](apps/aurora-core/licenses/SLF4J-LICENSE.txt) · [SLF4J](https://www.slf4j.org/license.html) |

Gson é copyright 2008 Google Inc. Alguns adaptadores agrupam as dependências ou as movem para um pacote interno do Aurora para evitar conflitos com mods.

## Referência técnica

Este repositório está sendo desenvolvido de forma independente. O Prism Launcher é citado apenas como referência técnica para interoperabilidade de instâncias e formatos de lançamento.

Prism Launcher é distribuído sob GPL-3.0. Caso qualquer código derivado dele seja incorporado ao Aurora, a distribuição do Aurora deverá cumprir integralmente a GPL-3.0, incluir a licença e os avisos de copyright aplicáveis, e declarar que o Aurora não é afiliado ao Prism Launcher.

Nenhum arquivo do Prism Launcher foi incorporado ao código do Aurora neste estágio.
