# Diagnóstico e ajuda

O **Aurora Doctor** analisa a instância local e apresenta evidências quando identifica uma causa provável. Depois de uma falha, abra o diagnóstico pelo aviso ou pelo editor da instância. Confira a versão do jogo, o loader, os problemas encontrados e o histórico da execução.

Para pedir uma segunda opinião, copie o resumo e revise o conteúdo antes de colá-lo no serviço de sua escolha. Para um problema de servidor, use a ajuda de diagnóstico e informe o erro observado. O compartilhamento é manual. Se o resumo omitir o erro específico, clique em **Incluir trecho filtrado na mensagem**. Ele acrescenta até 40 linhas recentes. Revise nomes e dados privados na prévia antes de copiar.

Para testar uma alteração, use uma [cópia de diagnóstico](diagnostic-lab.md). Os [pontos de recuperação](instance-recovery.md) permitem revisar e reverter as alterações cobertas.
