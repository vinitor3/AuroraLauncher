# Canais de distribuição

A beta é uma pré-release pública para testes. Cada tag identifica um commit e cada instalador tem SHA-256 e manifesto próprios. O README aponta diretamente para a beta escolhida, mesmo quando o GitHub apresenta versões estáveis em outro destaque.

Consulte o [fluxo de empacotamento](../release-workflow.md) e a [decisão de distribuição](ADR/ADR-036-beta-diagnostics.md). O [registro anterior à beta](https://github.com/vinitor3/AuroraLauncher/blob/088bf5b435b1b63e842c11ff1c01648b5e38bced/docs/engineering/RELEASE_STRATEGY.md) preserva o histórico das alphas.
