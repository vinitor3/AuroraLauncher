# Distribuição

Baixe a [beta para Windows x64](https://github.com/vinitor3/AuroraLauncher/releases/tag/v0.2.0-beta.1). O instalador, seu SHA-256 e o manifesto de origem ficam juntos na release.

As subpastas deste repositório preservam os JARs e instaladores históricos. A seleção usada no próximo build está em [active-mod-matrix.json](../scripts/active-mod-matrix.json). Consulte o [fluxo de empacotamento](../docs/release-workflow.md).
